# Day 1: My Academic Website

### Assignment Summary
This folder documents my first assignment: setting up a personal website hosted on GitHub Pages. The purpose of the site is to introduce my academic background, my current PhD research and some personal hobbies.

### Workflow and Execution
- **Repository Setup:** Created a new GitHub repository to serve as the host for my web files.
- **Content Creation:** Wrote the text for the website using GitHub Flavored Markdown (`index.md`), ensuring the formatting was clean and readable.
- **Site Generation:** Configured Jekyll using a `_config.yml` file to handle the background generation of the site.
- **Layouts & Styling:** Separated the HTML structure into a `_layouts/default.html` template file and integrated custom CSS to give the website a nice, polished design.
- **Submission:** Finalized the deployment and opened an issue on the main course repository with the links to my live site and code.

### AI Prompts & Assistance
I used AI as a guide to help me navigate the technical setup. A few prompts I used to get started were:
- "How to build a website using GitHub"
- "How to create a design similar to this"
- "Help me make my design a general template"
- "How to add picture files to the website"
